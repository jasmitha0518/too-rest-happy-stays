# TooRest – Tourist Hotel Booking Website

TooRest is a responsive tourist hotel booking website built using Lovable AI.
It allows users to search hotels by location, select check-in and check-out dates,
choose guests and rooms, and explore exclusive offers.

## 🌐 Live Demo
https://too-rest-happy-stays.lovable.app

## ✨ Features
- Hotel search by location/city
- Check-in and check-out date selection
- Guests and rooms selection
- Clean and modern UI
- Responsive design for mobile and desktop
- Exclusive offers section

## 🛠️ Tech Stack
- React
- TypeScript
- Vite
- CSS
- Lovable AI
